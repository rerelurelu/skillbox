# Code Review Criteria

Use these criteria when the reviewed scope is source code. This is the default type.

## 観点

- バグ、セキュリティ脆弱性、データ損失、クラッシュにつながる欠陥
- レースコンディション、設計上の欠陥、重大なロジックエラー
- **バージョン整合性**: 使用中の言語/フレームワーク/ライブラリのバージョンに対して、非推奨(deprecated)または将来廃止予定のAPIを使っていないか。そのバージョンで推奨される書き方（イディオム）に沿っているか。プロンプトに含まれる依存バージョン情報を基準に判断する
- パフォーマンス、保守性、軽微なロジックの抜け
- スタイルの好み、軽微な指摘、見た目上の指摘

## Severity基準

| Severity | Action | 基準 |
|----------|--------|------|
| **CRITICAL** | Must fix | バグ、セキュリティ脆弱性、データ損失、クラッシュ |
| **HIGH** | Must fix | 設計上の欠陥、レースコンディション、重大なロジックエラー、非推奨/廃止予定APIの使用 |
| **MEDIUM** | Consider | パフォーマンス、保守性、軽微なロジックの抜け |
| **LOW** | Skip | スタイルの好み、軽微な指摘、見た目上の指摘 |
